# System Overview

TokenBel Wiki is a **static website** — a Russian-language knowledge base generated by Hugo and served as Cloudflare Worker with Static Assets. There is no runtime script, no KV namespace, no bindings, and no origin server.

## Core Architecture

The system consists of **five independent layers** that compose into a static site pipeline:

1. **Content Layer** — Markdown articles and section landing pages with front matter
2. **Presentation Layer** — Hugo templates and Tailwind CSS for HTML rendering
3. **Media Publishing Toolchain** — Isolated Python CLI for image publishing to Cloudflare R2
4. **Site Build Toolchain** — Hugo-based build with Docker (local) and pinned binaries (Cloudflare)
5. **Cloudflare Deployment Target** — Worker with Static Assets serving the built `public/` directory

## Data Flow Summary

```
Content (Markdown + Front Matter)
    ↓ (Hugo reads hugo.yaml, discovers content/)
Presentation (Layouts + Templates)
    ↓ (Hugo renders Markdown → HTML)
Build Toolchain (Hugo CLI)
    ↓ (Generates public/ directory)
Cloudflare Worker (Static Assets)
    ↓ (Serves static files to users)
```

The Media Publishing Toolchain operates **in parallel** as an authoring-time workflow:

```
.wiki-media/inbox/ (images)
    ↓ (wiki-media CLI scans for upload: markers)
Cloudflare R2 (immutable objects)
    ↓ (Rewrites upload: → CDN URLs in content/)
Content Layer (updated Markdown)
    ↓ (Committed, triggers Hugo rebuild)
```

## Key Characteristics

- **Static-only**: No runtime code execution, no server-side processing
- **Decoupled**: Media publishing is separate from site building
- **Reproducible**: Pinned tool versions for both local and production builds
- **Immutable**: R2 objects are content-addressed and never overwritten
- **SEO-optimized**: Proper canonical URLs, robots meta, OpenGraph, JSON-LD
