## Category Analysis

### Hugo Build Outputs

```gitignore
public/
resources/
.cache/
.hugo_build.lock
```

**Build artifacts:**

| Directory/File | Generated by | Purpose |
|---------------|--------------|---------|
| `public/` | `hugo` command | Complete static site output |
| `resources/` | Hugo processing | Processed resources (images, etc.) |
| `.cache/` | Hugo | Hugo's internal cache |
| `.hugo_build.lock` | Hugo | Build lock file to prevent concurrent builds |

**Rule:** Never commit build outputs. Always regenerate with `make build` or `make production`.

### Node.js Dependencies

```gitignore
node_modules/
```

**Purpose:** Node.js package dependencies installed by `npm ci` or `npm install`.

**Rule:** Dependencies are managed by `package-lock.json`. Reinstall with `npm ci`.

### Cloudflare

```gitignore
.wrangler/
```

**Purpose:** Wrangler's local state and cache directory.

**Contents:**
- Deployment metadata
- API tokens (cached)
- Build artifacts

**Rule:** Wrangler recreates this directory as needed.

### wiki-media Tool

```gitignore
.wiki-media/
tools/wiki-media/.venv/
tools/wiki-media/.pytest_cache/
tools/wiki-media/.ruff_cache/
```

**Purpose:** wiki-media tool's working directories and caches.

| Directory | Purpose |
|-----------|---------|
| `.wiki-media/` | Inbox images, run backups, transaction state |
| `.venv/` | Python virtual environment |
| `.pytest_cache/` | pytest cache |
| `.ruff_cache/` | Ruff linter cache |

**Rule:** These directories contain local state or credentials. Never commit them.

**Note:** `.wiki-media/inbox/` contains images before publishing. These are published to R2 and referenced via CDN URLs, not committed.

### IDE Configuration

```gitignore
.idea/
.vscode/
*.swp
*.swo
```

**Purpose:** IDE-specific configuration and temporary files.

| File/Directory | IDE |
|---------------|-----|
| `.idea/` | JetBrains (IntelliJ, WebStorm, etc.) |
| `.vscode/` | Visual Studio Code |
| `*.swp` | Vim swap files |
| `*.swo` | Vim swap files |

**Rule:** IDE configuration is user-specific. Share via editorconfig or project settings files.

### OS Files

```gitignore
.DS_Store
Thumbs.db
```

**Purpose:** Operating system metadata files.

| File | OS |
|------|----|
| `.DS_Store` | macOS |
| `Thumbs.db` | Windows |

**Rule:** Never commit OS metadata files.

### Environment Files

```gitignore
.env
.env.local
.env.*.local
```

**Purpose:** Environment variable files containing secrets.

**Note:** `tools/wiki-media/.env` is **not** in the root `.gitignore` but is managed separately. It contains R2 credentials and should never be committed.

### Log Files

```gitignore
*.log
npm-debug.log*
```

**Purpose:** Log files from various tools.

**Rule:** Logs are ephemeral and should not be versioned.

### Temporary Files

```gitignore
*.tmp
*.temp
```

**Purpose:** Temporary files from editors or tools.

**Rule:** Temporary files are not part of the project.

## Important Exceptions

### Committed Build Outputs

These files **are** committed despite being build outputs:

| File | Reason |
|------|--------|
| `static/css/output.css` | Committed Tailwind output for development reference |
| `static/css/tailwind.min.css` | Committed Tailwind output (actually linked in templates) |

**Rule:** CSS outputs are committed to ensure reproducible builds without Tailwind CLI.

**Validation:** `make css-check` verifies these files match current Tailwind CLI output.

### Reserved Directories

These directories **exist** but are empty and committed:

| Directory | Purpose |
|-----------|---------|
| `assets/` | Reserved for Hugo assets pipeline (unused) |
| `scripts/` | Reserved for scripts (unused) |

**Note:** These directories are explicitly reserved and empty. Do not add files to them without updating the architecture.
