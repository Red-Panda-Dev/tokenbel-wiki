## Варианты
У сервиса есть несколько вариантов интеграций со сторонними программами и сервисами:

 - REST API
 - RSS лента
 - MCP

## REST API

Интеграция через **TokenBel REST API** предоставляет гибкий и стандартизированный способ подключения к сервису. Такой подход позволит получать актуальные данные о компаниях и токенах напрямую, без необходимости открывать сайт. Благодаря универсальному формату запросов REST API легко встраивается в любые системы, которые поддерживают работу с HTTP‑запросами, будь то аналитические инструменты или собственные приложения.

Такой метод интеграции подходит не только для специализированных систем, но и для популярных приложений управления финансами, например **GnuCash**, где данные о токенах и компаниях могут использоваться для учёта и анализа.</p>

## RSS
<p id="bkmrk-rss%E2%80%91%D0%BB%D0%B5%D0%BD%D1%82%D0%B0-%D1%81%D0%B5%D1%80%D0%B2%D0%B8%D1%81%D0%B0-%D0%BF%D0%BE"><a href="https://tokenbel.info/rss">RSS‑лента сервиса</a> позволяет оперативно отслеживать свежие эмиссии токенов, все предложения на вторичном рынке и их ключевые параметры. Такой формат интеграции удобен тем, что информация поступает автоматически и в привычном для многих систем виде, без необходимости ручного обновления или дополнительных запросов. Подписка на ленту обеспечивает постоянный доступ к актуальным данным, которые можно просматривать как в браузере, так и в специализированных агрегаторах.</p>

Это делает использование ленты максимально доступным и практичным. RSS‑лента прошла проверку на соответствие стандартам сервиса&nbsp;<strong>rssboard</strong>, что гарантирует корректность формата и совместимость с любыми приложениями, поддерживающими RSS.</p>

## MCP

Интеграция через **MCP (Model Context Protocol)** позволяет AI‑ассистентам и совместимым клиентам (например, [Claude Desktop](https://claude.ai/), [Cursor](https://cursor.com/), MCP Inspector) напрямую получать данные о белорусских ценных бумагах: токенах, акциях, облигациях и компаниях. Протокол работает по адресу `https://mcp.tokenbel.info/mcp` без необходимости аутентификации, так как все данные публичны.

Сервер предоставляет **10 инструментов** для работы с данными:
- Получение и списки токенов, акций, облигаций и компаний по UUID
- Поиск акций и облигаций по тикеру
- Поиск компаний по наименованию, полному названию или УНП
- Поддержка курсорной пагинации для списков

Для подключения в **Claude Desktop** добавьте в конфигурацию:

```json
{
  "mcpServers": {
    "tokenbel": {
      "url": "https://mcp.tokenbel.info/mcp"
    }
  }
}
```

Для проверки работы сервера можно использовать [MCP Inspector](https://github.com/modelcontextprotocol/inspector):

```bash
npx @modelcontextprotocol/inspector https://mcp.tokenbel.info/mcp
```

### Особенности интеграции:
- **Формат данных**: JSON через Streamable HTTP
- **Кэширование**: на уровне Cloudflare Workers KV (TTL 300–180с в зависимости от типа запроса)
- **Ограничения**: рекомендуемый лимит — 50 запросов/минуту с IP
- **CORS**: поддержка любых источников (`*`), методы `GET, POST, DELETE, OPTIONS`
