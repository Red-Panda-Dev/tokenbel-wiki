## Введение

За первую декаду августа мы запустили страницу курсов валют и драгоценных металлов — теперь динамика USD, EUR, RUB, а также золота, серебра, платины и палладия видна в одном месте с интерактивными графиками. Параллельно решили давнюю проблему с полугодовыми купонами для облигаций и добавили поле валюты замещения, что особенно важно для банковских выпусков. Попутно улучшили графики акций и облигаций: средние линии дивидендов, переключение валют, психологические уровни.

---

## Главное

Страница курсов валют и металлов стала основным обновлением периода. Теперь пользователи видят актуальную динамику по всем основным валютам и активам Нацбанка с возможностью переключения между дневными, недельной и месячной детализацией. Графики поддерживают скользящие средние, изменение с начала периода, уровни поддержки/сопротивления и единую цветовую палитру для каждого актива.

Для инвесторов в облигации мы решили давнюю проблему с полугодовыми купонами: теперь эмиссии с частыми выплатами корректно распознаются и отображаются. А для замещающих облигаций появился знак валюты, по которой рассчитываются выплаты — это помогает не путать их с обычными выпусками в белорусских рублях.

---

## Что стало удобнее

### Для инвесторов

- **Страница курсов валют и металлов:** семь панелей с графиками, фильтры по периоду и зернистости, инструменты анализа — скользящие средние, процентное изменение, уровни поддержки/сопротивления.
- **Средняя линия дивидендов:** на графике выплат по акциям появилась горизонтальная линия со средним значением — удобно сравнивать текущий год с исторической нормой.
- **Переключение валюты на графике облигаций:** ценовую историю можно посмотреть в BYN, USD или EUR — как и у акций.

[![Калькулятор облигаций](https://cdn-wiki.tokenbel.info/wiki/media/images/ce/ce230a2f3fb53b650bc7e87c71dd8c3e78cdbc2ad6c034d03a6a32755a626960.png)](https://cdn-wiki.tokenbel.info/wiki/media/images/ce/ce230a2f3fb53b650bc7e87c71dd8c3e78cdbc2ad6c034d03a6a32755a626960.png)

- **Психологические уровни для валют:** уровни поддержки/сопротивления теперь отображаются на круглых значениях (2.80, 3.00, 3.20), а не на технической сетке.
- **Знак замещающей облигации:** на карточке и в каталоге видно, если выплаты привязаны к иностранной валюте.

### Для данных и страниц

- **Единый источник данных:** курсы валют и металлов теперь загружаются параллельно из API Нацбанка, а на дашборде отображаются с единой логикой.
- **Уточнённые фильтры:** панель фильтров страницы курсов приведена к каталоговому стилю с пояснениями по скользящим средним.

---

## Исправили

- Исправили обработку нулевых значений в серии курсов валют — на графиках больше нет нулевых спиков вместо пропущенных данных.
- Исправили логику расписания купонов облигаций: полугодовые графики теперь корректно восстанавливаются даже без даты выпуска.

---

## Технически

- Реализован Content-Security-Policy через meta-tag с поддержкой всех необходимых доменов для внешних библиотек.
- Поднята версия API до v7.14.0 с поддержкой нового типа периодичности `PERCENT_PAYMENT_BIMONTHLY`.
- Обновлён воркер распознавания новостей: теперь он учитывает PDF и DOC файлы, прикреплённые к новости, чтобы событие содержало более полноценную информацию.
