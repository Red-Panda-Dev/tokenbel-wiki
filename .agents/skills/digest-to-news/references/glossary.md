# Глоссарий: как называть вещи в новости

Этот файл — единый источник запрещённых и рискованных слов. `scripts/check_digest.py`
читает термины в обратных кавычках из первой колонки таблиц разделов
«Канцелярит», «Жаргон» и «Написание названий». Термины — основы слов: `реализован`
ловит «реализована», «реализованы».

## Канцелярит

Запрещено везде, включая `## Технически`.

| Не пишем                  | Пишем                                                           |
| ------------------------- | --------------------------------------------------------------- |
| `реализован`              | «сделали», «появилось», «теперь можно»                          |
| `реализация функционал`   | назвать саму возможность                                        |
| `функционал`              | «возможность», «раздел», «инструмент» — или конкретное название |
| `оптимизирован`           | что именно стало быстрее и где                                  |
| `в рамках`                | убрать оборот целиком                                           |
| `данное обновление`       | «это обновление» или вообще без оборота                         |
| `рады представить`        | начать сразу с изменения                                        |
| `проведена работа`        | что получилось в результате                                     |
| `осуществл`               | обычный глагол: «делаем», «отправляем»                          |
| `позволяет пользователям` | «можно», «теперь видно»                                         |
| `значительно улучш`       | конкретный эффект или ничего                                    |
| `было добавлено`          | «добавили», «появилось»                                         |
| `произведен`              | обычный глагол                                                  |

## Жаргон

Запрещено вне `## Технически`. Внутри раздела допустимо, но лучше заменить словами о
пользе.

| Не пишем       | Пишем для читателя                                                     |
| -------------- | ---------------------------------------------------------------------- |
| `воркер`       | «отдельный сервис», «фоновая служба»                                   |
| `worker`       | то же                                                                  |
| `эндпоинт`     | «открытый метод API» (только в «Технически»)                           |
| `endpoint`     | то же                                                                  |
| `рефактор`     | не упоминать; если важно — «переписали внутри, снаружи всё как раньше» |
| `миграци`      | для БД — не упоминать; для переезда сервиса — «переехали»              |
| `Redis`        | «кэш», «быстрее открывается повторно»                                  |
| `кэширу`       | «повторно открывается быстрее»                                         |
| `WASM`         | не упоминать вне «Технически»                                          |
| `Rust`         | то же                                                                  |
| `SSR`          | не упоминать                                                           |
| `Alpine`       | не упоминать                                                           |
| `JWT`          | не упоминать                                                           |
| `bearer`       | не упоминать                                                           |
| `msgspec`      | не упоминать                                                           |
| `Tailwind`     | «оформление», «стили»                                                  |
| `sankey`       | «диаграмма потоков», «схема движения денег»                            |
| `payload`      | не упоминать                                                           |
| `контракт API` | «формат ответа» (только в «Технически»)                                |
| `инвалидаци`   | «данные обновляются сразу после изменения»                             |
| `дедупликаци`  | «убираем дубли», «склеиваем одинаковые»                                |
| `окно выплат`  | «период выплаты»; если важна дата — «первый день периода выплаты»      |
| `окна выплат`  | то же                                                                  |
| `snapshot`     | «срез», «состояние на дату»                                            |
| `фича`         | «возможность»                                                          |

## Написание названий

Проверяется с учётом регистра: первая колонка — неверное написание.

| Неверно         | Верно                                           |
| --------------- | ----------------------------------------------- |
| `banki24`       | Banki24.by                                      |
| `minfin`        | MinFin                                          |
| `fainex`        | Fainex                                          |
| `finstore`      | Finstore                                        |
| `bynex`         | Bynex                                           |
| `whitebird`     | Whitebird                                       |
| `Tokenbel`      | TokenBel                                        |
| `tokenbel.info` | TokenBel или dashboard.tokenbel.info (в ссылке) |
| `телеграм`      | Telegram                                        |
| `Телеграм`      | Telegram                                        |

## Предметные слова, которые оставляем

Читатель — частный инвестор, ему эти слова знакомы, объяснять не нужно:
токен, эмиссия, облигация, купон, погашение, YTM / доходность к погашению, дивиденд,
вторичный рынок, эмитент, УНП, ЕГР, НБРБ, БВФБ, ставка рефинансирования, вклад,
драгметаллы, портфель, позиция, платформа (Finstore, Bynex и т. д.).

Если слово нужно, но может быть непонятно (например, «плавающий купон»), объясните его
одной короткой фразой при первом упоминании.
