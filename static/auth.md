# auth.md — доступ агентов к TokenBel Wiki

`https://wiki.tokenbel.info/` — публичная статическая база знаний. Этот документ
опубликован по спецификации [auth.md](https://auth.md/) и описывает правила
аутентификации, регистрации и получения доступа для автономных агентов
(AI-агентов, краулеров, ассистентов и иных программных клиентов).

## Аудитория агентов

Документ адресован программным агентам, которые автоматически читают Wiki:
поисковым и AI-краулерам, ассистентам, отвечающим на вопросы по материалам
базы, и интеграциям, забирающим публичный контент. Человеческим пользователям
аутентификация также не требуется.

## Регистрация

Регистрация агентов **не предусмотрена**. У сайта нет эндпоинтов регистрации и
провижининга, нет выдачи учётных данных, API-ключей или токенов. Создавать
учётную запись, запрашивать ключ или подтверждать e-mail перед чтением не
нужно.

## Поддерживаемые методы доступа

Поддерживается единственный метод — **анонимный доступ**: любой публичный путь
доступен без аутентификации (обычно `GET`). Дополнительно для агентов:

- `https://wiki.tokenbel.info/robots.txt` — политика для краулеров и
  Content-Signal (`ai-train=yes, search=yes, ai-input=yes`);
- `https://wiki.tokenbel.info/sitemap.xml` — карта сайта для обхода;
- `https://wiki.tokenbel.info/llms.txt` — машиночитаемое описание базы;
- запрос с заголовком `Accept: text/markdown` возвращает Markdown-версию
  страницы.

## Использование учётных данных

Учётные данные не нужны и не выдаются. Если клиентский фреймворк требует
выбрать тип идентичности, указывайте `anonymous` (см. метаданные ниже).
Типы `identity_assertion` (ID-JAG) и `verified_email` не поддерживаются:
личных кабинетов и защищённых ресурсов на Wiki нет.

Смежные сервисы TokenBel (Dashboard `dashboard.tokenbel.info`, MCP-сервер
`mcp.tokenbel.info`) — отдельные ресурсы со своими политиками доступа;
этим документом их аутентификация не описывается.

## Метаданные

```json
{
  "identity_types_supported": ["anonymous"],
  "anonymous": {
    "credential_types_supported": [],
    "claim_uri": "https://wiki.tokenbel.info/auth.md"
  }
}
```

OAuth Protected Resource Metadata (`/.well-known/oauth-protected-resource`) и
Authorization Server Metadata (`/.well-known/oauth-authorization-server`)
намеренно не публикуются: у Wiki нет API, защищённых ресурсов и
OAuth-серверов, а `/auth.md` самодостаточен.
